# Doctor Appointment App

A simple multi-page React application built with Vite and React Router to view doctors, filter by specialization, check availability, and manage appointments.

## Features

- **Home Page (`/`):** Summary counts for total doctors, doctors available today, and booked appointments.
- **Doctors List (`/doctors`):** View all doctors, filter by specialization (Cardiologist, Dermatologist, Orthopedic, Pediatrician, Dentist), and book/cancel appointments.
- **Doctor Details (`/doctors/:id`):** Detailed view showing hospital, experience, rating, fee, and available slots.
- **My Appointments (`/appointments`):** View all booked appointments and calculate the total consultation fee.
- **Badges:** Indicates doctor availability (Available Today / Not Available) and experience level (Senior Doctor).

## How to Run the Project Locally

Follow these simple steps in your terminal:

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to the local URL shown in your terminal (usually `http://localhost:5173`).
